Рабочая папка - это файл проекта, которые находятся на компьютера.

Индекс - это область git куда добавляются изменения .

Коммит - это сохраненное состояние проекта.


Git - программа для отслеживания изменений в проекте.


Github - платформа для хранения и совместной работы с репозиториями.



git diff и git diff --staged  - дифф изменения еще не добавленные в индекс, а --staged изменения уже добавленные в индекс.

git status - показывает статус рабочей директории 

git diff - показывает измения еще не добавленные в индекс..

git diff --staged -показывает изменения уже добавленные в индекс.

ветка - отдельная линия разработки указывающа на определенный  коммит.

коммит - сохраненная версия изменений проекта с описанием этих изменений .

новый коммит - создает новую точку в истории текущей .

слияние - объединяет изменений из однй ветки в другую.
